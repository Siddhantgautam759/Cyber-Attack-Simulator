
#CyberSim – Cyber Attack Simulator

A fully interactive, frontend-based cybersecurity learning platform featuring live demonstrations of common web attacks. Built using HTML, CSS, JavaScript, and designed with a premium cyberpunk UI.

This project is safe for educational use and does NOT perform any real malicious actions. All attacks are simulated client‑side.

🚀 Features
🟢 1. SQL Injection Simulator

Shows how unsafe queries are built

Displays final SQL query in real-time

Demonstrates classic payloads like ' OR '1'='1 and admin'--

🟣 2. XSS (Cross-Site Scripting) Simulator

Detects <script> tags

Shows “script executed” message safely

No actual execution of harmful scripts

🔵 3. Brute Force Attack Visualizer

100% safe browser-based simulation

Auto-detects charset (a-z, A-Z, 0-9, symbols)

Generates attempts sequentially

Accurate match detection

Real-time progress bar

Works for mixed passwords like: A1@b, #9Z, abc123!

🟠 4. Phishing Awareness Module

Shows common phishing-style messages

Helps users identify dangerous keywords

Includes security education

🛠️ Tech Stack

HTML5 – structure

CSS3 (Cyberpunk neon theme) – UI/UX

JavaScript (Vanilla JS) – app logic

No backend required, fully client-side
