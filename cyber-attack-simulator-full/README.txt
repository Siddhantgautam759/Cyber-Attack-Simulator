Cyber Attack Simulator - Full package
Frontend (static) + Backend (Node.js Express demo)

How to run frontend:
- Open frontend/index.html in a browser (works locally).
- Or serve with a static server.

How to run backend (optional, for server demos):
1. cd backend
2. npm install
3. npm start
Server listens on http://localhost:5000

Frontend buttons that call server expect backend running at http://localhost:5000
